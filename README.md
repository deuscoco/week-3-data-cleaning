# ☁️ Google Apps Script Web System Suite
This repository contains three web-based systems developed using **Google Apps Script** and integrated directly with **Google Spreadsheet as the database**.
All systems run entirely on the cloud without requiring any additional hosting server.

# 🏫 1️⃣ Lecturer Schedule Website
A web-based academic information system used to display and manage lecturer schedules in a **structured, dynamic, and real-time** way.
## 🎯 Objectives
- Digitalize lecturer schedules
- Reduce manual recording errors
- Display schedules automatically from a spreadsheet
- Simulate a cloud-based academic system
## 🧩 Key Features
- 📅 Lecturer schedule display
- 🔎 Filter by day / lecturer name
- 🔄 Automatic data updates from Google Sheet
- 🌐 Direct hosting via Apps Script

# ☕ 2️⃣ Café Point of Sale Web System
A web-based point of sale system designed to help manage sales transactions for MSMEs or small cafés.
All transactions are saved automatically to Google Spreadsheet in real time.
## 🎯 Objectives
- Digitalize manual cashier systems
- Automatic transaction recording
- Centralized product management
- Simple sales summary
## 🧩 Key Features
- 🔐 Login (single role)
- 🛒 Product input & search
- 🧾 Simple receipt printing
- 📊 Daily transaction summary
- 🏷️ Barcode support
- 📡 Automatic storage to Google Sheet

# 📝 3️⃣ Attendance Web System
A web-based attendance system used to record attendance digitally and automatically.
Attendance data is saved directly to Google Spreadsheet, complete with timestamps.
## 🎯 Objectives
- Digitalize manual attendance recording
- Automatic time logging
- Monitoring attendance data
- Simulate a cloud-based administrative system
## 🧩 Key Features
- 📋 Attendance input form
- 🕒 Automatic timestamp
- 🧑 Data input (Name / Student ID / Class)
- 📊 Real-time storage to Google Sheet
- 🌐 Deployed as a Web App
